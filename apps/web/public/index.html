Threat model

What we defend against.

Leaked credentials

Commit status fails; values never leave unredacted.

Poisoned dependencies

Lockfiles checked against known-bad releases.

CI injection

Event text in shell steps and fork checkouts flagged.

Phishing links

Lookalikes, homographs and redirects, never fetched.

Cross-tenant linking

Per-account keys and row-level security.

Forged reports

Signed receipts with digest checks.

Session theft

Encrypted HttpOnly cookies, same-origin gate.

Scanner abuse

Size, time and rate limits on every input.
